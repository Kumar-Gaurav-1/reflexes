## 2024-02-23 - Avoid GC micro-stutters and improve cache locality in AR loops
**Learning:** High-frequency `requestAnimationFrame` loops for AR and Canvas processing are highly sensitive to Garbage Collection (GC) pauses caused by allocating small arrays or objects (like `[{x, y}]`) and using array iteration methods (`.forEach`). Furthermore, 2D array nested loops for image processing should always structure `y` as the outer loop and `x` as the inner loop to maintain cache locality, and should pre-calculate bounds to prevent per-iteration bounds checks.
**Action:** Unroll small static array operations into direct variable assignments within render loops. Order nested iteration over `ImageData` with `y` (rows) as the outer loop, and use `Math.max`/`Math.min` to clamp boundaries before the loops begin.
