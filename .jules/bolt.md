## 2024-05-15 - [Optimize nested loops by iterating y first and hoisting row-invariant calculations]
**Learning:** [When processing 1D canvas image data arrays representing 2D space, optimize nested loops by iterating `y` (rows) first and then `x` (columns) to match row-major memory layout, which improves CPU cache hit rates. Additionally, hoist row-invariant calculations (like `y * width`) out of the inner loop to minimize computation. Additionally, pre-calculate and clamp loop boundaries (e.g., using `Math.max` and `Math.min`) outside the nested loops to avoid expensive per-pixel conditional branch evaluations.]
**Action:** [Pre-calculate loop boundaries `startX`, `endX`, `startY`, `endY` using Math.max and Math.min before the loops. Iterate `y` before `x`. Calculate `y * width * 4` (e.g., `rowOffset`) in the `y` loop and use it in the inner `x` loop.]
