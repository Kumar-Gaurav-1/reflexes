## 2024-10-24 - Optimizing High-Frequency Canvas Array Processing
**Learning:** When dealing with 1D image data arrays inside a high-frequency `requestAnimationFrame` loop (e.g. 60+ FPS for AR tracking), using array iteration methods like `forEach` and creating dynamic inline arrays triggers frequent Garbage Collection (GC) which leads to micro-stutters. Furthermore, nested loops checking bounds on every iteration, and iterating `x` (columns) before `y` (rows), causes branching overhead and sub-optimal CPU cache hits since image data is stored row-by-row in memory.
**Action:** Unroll static arrays and replace higher-order array methods with standard `for` loops in the critical render path. Always pre-calculate and clamp nested loop boundaries using `Math.max` and `Math.min` to avoid inner-loop conditionals. Lastly, when iterating 1D arrays representing 2D space, iterate `y` (rows) in the outer loop and `x` (columns) in the inner loop to match the row-major memory layout, maximizing CPU cache locality.
