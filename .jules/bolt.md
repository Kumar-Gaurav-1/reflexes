## 2024-10-07 - Avoid Garbage Collection stutters in requestAnimationFrame
**Learning:** In high-frequency render loops like `requestAnimationFrame` used for image processing and motion detection, avoiding object or array allocations (e.g. `[{x: 5, y: 5}, ...]`) and callback definitions (e.g. `.forEach`) on every frame prevents garbage collection stutters. Also, conditionally validating coordinates inside a per-pixel double for-loop introduces massive CPU overhead due to continuous branch evaluations.
**Action:** Unroll loops when the array size is static and known, and use standard `for(let i=0; i<length; i++)` instead of `.forEach`. When dealing with boundary conditions in inner loops, use `Math.max()` and `Math.min()` to calculate clamped outer boundaries beforehand to remove inner conditional branching.
