## 2024-08-07 - Optimize AR motion detection loop
**Learning:** In high-frequency `requestAnimationFrame` loops handling pixel data (e.g., `detectMotion` in `src/components/ar-drill-view.tsx`), computing object positions or array offsets on the fly degrades performance. Furthermore, iterating columns (x) then rows (y) leads to poor cache locality. Iterating rows then columns is much faster for row-major formats like `ImageData`. Inner loop bounds checks also add up.
**Action:** Extract constant corner sample positions into a pre-calculated `Int32Array` of byte offsets outside the component loop. Refactor 2D loops to iterate row-by-row (y first, then x), and pre-calculate array boundaries with `Math.max` and `Math.min` to avoid inner-loop bound conditional checks on every pixel.
