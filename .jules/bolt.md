## 2025-02-20 - Optimize requestAnimationFrame pixel processing loop
**Learning:** For high-frequency requestAnimationFrame loops (like AR tracking with canvas data), avoid allocating new objects or arrays and using array iteration methods like `.forEach()` to prevent Garbage Collection micro-stutters. Additionally, when processing 1D canvas image data arrays representing 2D space, iterate `y` (rows) first and then `x` (columns) to match row-major memory layout for better CPU cache hits, and hoist row-invariant calculations (like `y * 160 * 4`) and pre-calculate loop boundaries outside the inner nested loop.
**Action:** Unroll static arrays, use row-major order iteration (`y` then `x`), pre-calculate loop limits with `Math.max`/`Math.min`, and move row-invariant variable assignments outside the inner loop to minimize per-pixel computation and micro-stutters.
