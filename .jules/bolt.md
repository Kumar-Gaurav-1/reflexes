## 2025-02-12 - AR Kinetic Processing Loop Optimization
**Learning:** High-frequency canvas processing loops (`requestAnimationFrame` running `getImageData`) are extremely sensitive to Garbage Collection micro-stutters and cache locality. Allocating objects (like the `cornerSamples` array) inside the loop caused GC pauses. Additionally, checking bounds conditionally inside a nested pixel-processing loop creates significant branching overhead, and traversing columns before rows causes cache misses.
**Action:** Unroll static arrays and loops for global motion checking. Pre-calculate clamped array boundaries using `Math.max` and `Math.min` before entering nested loops. Always structure nested typed array iteration with `Y` (rows) as the outer loop and `X` (columns) as the inner loop to ensure contiguous row-major memory access.
