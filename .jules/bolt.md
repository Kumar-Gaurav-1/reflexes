## 2025-02-12 - AR Kinetic Engine Loop Optimization
**Learning:** High-frequency `requestAnimationFrame` loops analyzing canvas pixel data are extremely sensitive to Garbage Collection. Using inline object arrays (`[{x: 5, y: 5}, ...]`) and `.forEach()` within the render loop allocates memory every frame, leading to GC micro-stutters in the AR view. Additionally, evaluating conditional branch logic (`if (x < 0 || x >= 160) continue`) inside an inner nested loop executed per-pixel is expensive.
**Action:** Unroll static arrays and calculate indices mathematically to avoid array instantiation and array iteration methods. Pre-calculate and clamp nested loop boundaries (e.g., using `Math.max` and `Math.min`) outside the loop to eliminate per-pixel boundary checking conditionals.
