## 2023-10-27 - RequestAnimationFrame Micro-Optimizations
**Learning:** In high-frequency rendering loops like `requestAnimationFrame` for AR tracking, micro-stutters and performance degradation can be caused by continuous garbage collection micro-pauses. This is often the result of using array iteration methods (e.g., `Array.prototype.forEach()`) and allocating objects inside the loop (e.g., creating arrays of coordinates). Furthermore, per-pixel conditional boundary checks inside nested loops can cause expensive conditional branch evaluations.
**Action:** When optimizing high-frequency loops, avoid object/array allocation, use standard `for` loops instead of array iteration methods, and unroll static loops when possible. Also, pre-calculate and clamp loop boundaries outside the inner loops using `Math.max` and `Math.min` to avoid unnecessary operations inside the inner loops.
