## 2025-03-05 - Optimize nested loops and allocations in requestAnimationFrame
**Learning:** In high-frequency loops like `requestAnimationFrame` for AR pixel processing, declaring dynamic arrays and using `.forEach()` inside the function allocates new objects per frame, leading to garbage collection micro-stutters. Also, in nested pixel loops, conditionally checking loop boundaries per-pixel and having column (`x`) as the outer loop instead of row (`y`) can cause poor cache locality (non-contiguous memory access).
**Action:** Unroll static array loops (like sampling fixed coordinates) by pre-calculating the exact array indices. When scanning image data arrays, always ensure `y` is the outer loop (row-major) for contiguous memory reading, and pre-calculate bounding boxes using `Math.max` and `Math.min` before starting the loop to eliminate per-pixel conditionals.
