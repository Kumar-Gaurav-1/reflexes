## 2024-05-19 - AR Drill Loop Optimization
**Learning:** In high-frequency `requestAnimationFrame` loops (like the AR tracking view), allocating arrays and using array iteration methods like `.forEach()` causes GC micro-stutters. Also, nested loop ordering is critical for 2D pixel processing: iterating over `y` (rows) in the outer loop and `x` (columns) in the inner loop ensures contiguous memory access (row-major order), improving cache locality. Pre-calculating loop boundaries outside the loop prevents expensive per-pixel conditional checks.
**Action:** Unroll static arrays and use direct variable assignments in animation frames. Ensure nested loops for image data iteration are structured row-by-row (y-outer, x-inner) and pre-calculate any boundaries clamped by `Math.max`/`Math.min` before the loops start.
