## 2024-10-24 - Optimizing Image Processing in requestAnimationFrame
**Learning:** In high-frequency 60fps loops like `requestAnimationFrame` processing canvas pixels, allocating arrays or objects per frame (e.g., `const samples = [{x,y}]`) causes unnecessary garbage collection micro-stutters. Also, nested loops traversing 1D image arrays (like `ImageData`) must iterate with `y` (rows) as the outer loop and `x` (cols) as the inner loop to maintain contiguous memory access and improve cache locality. Bounds checking should also be clamped outside the inner loop to prevent branch evaluation per pixel.
**Action:** Unroll static arrays/objects into direct variable assignments, compute boundary limits before loops using `Math.max`/`Math.min`, and always structure 2D array traversal in row-major order (y outer, x inner).
