## 2024-05-15 - Optimize kinetic pixel processing loop
**Learning:** In high-frequency loops like `requestAnimationFrame` that process pixel data from `getImageData`, minor structural changes drastically improve execution speed and reduce Garbage Collection (GC) stutters. Specifically, unrolling small static arrays avoids GC micro-stutters by eliminating dynamic allocations. Replacing array `.forEach()` iterations with standard `for` loops prevents the creation of closure objects on every frame. Pre-calculating clamped boundaries (using `Math.max` and `Math.min`) outside of nested pixel loops is significantly faster than using branch checks (`if (x < 0 || ...)`) inside the tight loop. Finally, ordering nested loops with `y` (rows) as the outer loop and `x` (columns) as the inner loop is essential for cache locality, as it ensures memory is accessed contiguously in row-major order.
**Action:** Always structure pixel processing and canvas `requestAnimationFrame` loops to minimize allocations, use standard `for` loops, pre-calculate boundary bounds, and access 1D typed arrays (like `ImageData.data`) using contiguous row-major `[y][x]` loop ordering.
