## 2024-05-18 - requestAnimationFrame Kinetic High-Frequency Loop Optimization
**Learning:** In high-frequency rendering loops like React's `requestAnimationFrame` inside a `useCallback` (e.g., kinetic hand-tracking logic where 60fps frame processing occurs), dynamic array allocations like `const cornerSamples = [...]` and array iterators like `cornerSamples.forEach(...)` trigger constant garbage collection overhead resulting in micro-stutters. Also, nested pixel loops that calculate boundary checks `if (x < 0 || x >= 160 || y < 0 || y >= 120) continue` execute on every single pixel evaluated (potentially thousands of times per frame), adding extreme branch evaluation cost.
**Action:** Unroll static arrays and object allocations outside the loop or hardcode them directly. Pre-calculate and clamp outer loop boundaries once per target check using `Math.max()` and `Math.min()` to entirely avoid conditional checks inside the inner intensive O(N^2) pixel inspection loops. Replace `forEach` with traditional `for` loops.
