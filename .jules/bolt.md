## 2025-02-12 - AR Canvas Motion Loop Optimization
**Learning:** Nested coordinate loops and boundary checking inside `requestAnimationFrame` for canvas manipulation is a major bottleneck. Caching target boundary states and switching to pre-calculated byte offsets allows the inner pixel processing loop to bypass branch predictions and boundary condition checks, significantly speeding up execution (by over 40% in benchmarks). Combining `Int32Array` with these precalculated offsets yields optimal performance.
**Action:** When iterating over predictable windows within a large buffer (like image data), calculate a single safety check for the entire window. If safe, iterate over a precalculated `Int32Array` of byte offsets from the center point instead of using multiple `for` loops with x/y coordinate math and boundary checking per pixel.
