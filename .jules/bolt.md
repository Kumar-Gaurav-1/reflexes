## 2023-10-22 - Optimizing canvas pixel processing loops
**Learning:** For high-frequency `requestAnimationFrame` loops (e.g., AR tracking or canvas rendering), allocating new objects/arrays and using array iteration methods like `.forEach()` causes Garbage Collection micro-stutters. Also, when processing 1D canvas image data arrays representing 2D space, iterating `y` (rows) first and then `x` (columns) matches row-major memory layout, which improves CPU cache hit rates.
**Action:** Unroll static arrays and use direct variable assignments instead. Optimize nested loops by iterating `y` (rows) first and then `x` (columns). Pre-calculate and clamp loop boundaries (e.g., using `Math.max` and `Math.min`) outside the nested loops to avoid expensive per-pixel conditional branch evaluations.
