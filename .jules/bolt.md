## 2024-10-21 - High-frequency Loop Optimizations in requestAnimationFrame
**Learning:** In high-frequency render loops (e.g., canvas pixel processing via `requestAnimationFrame`), avoiding object/array allocations (like `[{x,y}, ...]`), replacing `.forEach()` with classic `for` loops, pre-calculating boundaries with clamping (`Math.max`/`min`), and restructuring nested loops for memory locality (iterating `y` rows before `x` columns and hoisting row calculations) are necessary to minimize Garbage Collection micro-stutters and improve CPU cache hit rates.
**Action:** Always unroll static arrays, pre-clamp iteration bounds outside the loop, use row-major ordering for 1D arrays representing 2D space, and favor direct variable assignment/loops over array methods in `requestAnimationFrame` blocks.
