## 2025-02-18 - Optimize Image Processing Loops in requestAnimationFrame
**Learning:** In high-frequency 60fps React components performing image data analysis (like canvas pixel manipulation in AR trackers), iterating over 1D flat arrays representing 2D spaces should always be done in row-major order (outer loop Y, inner loop X) to improve CPU cache hits. Furthermore, repeatedly evaluating out-of-bounds checks `if (x < 0 || x >= width)` inside the tightest inner loop causes unnecessary conditional branching that impacts frame times.
**Action:** When implementing pixel scanning in `requestAnimationFrame`, always pre-calculate and clamp loop boundaries (`Math.max(0, ...)`, `Math.min(width, ...)`) outside the nested loops, and iterate `y` then `x` to respect row-major memory layout, hoisting row invariants (`y * width`) out of the inner loop.
