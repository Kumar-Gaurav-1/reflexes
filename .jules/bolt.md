## 2024-09-13 - Optimizing high-frequency requestAnimationFrame loops
**Learning:** In high-frequency 60FPS render loops (`requestAnimationFrame` for AR pixel processing), mapping over newly allocated arrays (like `.forEach` on inline arrays) triggers garbage collection micro-stutters. Nested loops processing 1D flat arrays of image data perform significantly better when utilizing row-major memory access (outer `y`, inner `x`), which improves CPU cache locality. Evaluating conditional branches (checking loop bounds) inside tight loops adds major overhead.
**Action:** Unroll static arrays. Use direct variable access. Always structure nested image loops `y` then `x`. Pre-calculate loop bounds with `Math.min` and `Math.max` outside the tight loop to eliminate internal branch operations.
