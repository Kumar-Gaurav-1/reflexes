## 2024-05-18 - Avoid array allocation and optimize iteration in requestAnimationFrame
**Learning:** In high-frequency rendering loops like `requestAnimationFrame` handling AR tracking or motion detection on a canvas, allocating arrays on every frame (e.g. `[{x: 5, y: 5}, ...]`) and using iteration methods like `.forEach` cause garbage collection pauses that interrupt smooth rendering. Additionally, iterating image pixel data with `x` as outer loop and `y` as inner loop is suboptimal.
**Action:** Unroll static iterations into direct assignments instead of allocating arrays. For 2D image data iteration, pre-clamp boundary ranges (using `Math.max` and `Math.min`) outside the loop to avoid running bounds checks inside the loop, and always use row-major ordering (`y` as outer loop, `x` as inner loop) to optimize cache locality since typed arrays store pixels linearly row by row.
