## 2024-05-18 - Avoid Garbage Collection in requestAnimationFrame
**Learning:** In high-frequency React `requestAnimationFrame` loops (like AR kinetic tracking), declaring arrays (e.g., `const cornerSamples = [...]`) and using array iteration methods (e.g., `.forEach()`) inside the loop creates constant new object allocations and closures. This causes garbage collection micro-stutters and measurable performance hits in tight loops that execute 60 times a second. Also, re-evaluating boundaries in nested loops adds overhead.
**Action:** Extract static arrays completely outside the component or loop. Use traditional `for` loops (e.g., `for (let i = 0; i < len; i++)`) instead of `.forEach()`. Pre-calculate bounding box clamps (using `Math.max` and `Math.min`) outside nested loops.
