## 2024-05-18 - Optimize AR target detection loops
**Learning:** High-frequency loops like `requestAnimationFrame` for AR canvas processing suffer from GC micro-stutters when repeatedly allocating arrays (e.g., `cornerSamples`). Furthermore, iterating 2D image arrays using nested loops with `x` as the outer loop and `y` as the inner loop causes poor cache locality (column-major access). Boundary condition checking via `if` statements inside the innermost loop significantly degrades performance.
**Action:** Unroll static arrays to avoid object/array allocation and `forEach` calls in rAF loops. Always structure nested pixel loops with `y` (rows) as the outer loop and `x` (columns) as the inner loop for contiguous memory access (row-major). Pre-clamp loop boundaries using `Math.max` and `Math.min` before entering the loops to eliminate inner-loop conditional checks.
