## 2024-05-14 - Optimize requestAnimationFrame pixel processing loops
**Learning:** In high-frequency `requestAnimationFrame` loops (like AR motion tracking), iterating over static arrays using methods like `.forEach()` causes micro-allocations that can trigger garbage collection stutters. Additionally, iterating over 2D image data arrays should prioritize `y` (rows) as the outer loop and `x` (columns) as the inner loop to ensure contiguous, row-major memory access for optimal cache locality. Finally, pre-calculating and clamping loop boundaries outside the inner loops avoids expensive per-pixel conditional branch evaluations.
**Action:** Always unroll static arrays (e.g., using `pos1`, `pos2`, etc.) in `requestAnimationFrame` loops to avoid `.forEach()` allocation. Pre-calculate and clamp loop boundaries outside the nested loops. Structure nested X/Y loops with `y` as the outer loop and `x` as the inner loop for contiguous, row-major memory access when iterating over image data arrays.
