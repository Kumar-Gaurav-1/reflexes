## 2024-05-18 - Optimize kinetic motion detection loop in AR Drill View
**Learning:** For high-frequency `requestAnimationFrame` loops (e.g., AR tracking or canvas rendering), allocating arrays or objects on every frame (like `[{x: 5, y: 5}, ...]`) and using array iteration methods (`.forEach`) can cause Garbage Collection micro-stutters. Additionally, nested pixel processing loops over image data arrays are more performant when the row (`y`) is the outer loop and the column (`x`) is the inner loop, due to row-major cache locality. Clamping bounds outside the loop instead of checking them conditionally inside the loop avoids unnecessary execution overhead.
**Action:** Unroll static arrays and assign variables directly. Structure nested image data loops for row-major contiguous memory access (`y` outer, `x` inner). Clamp array boundaries with `Math.max` and `Math.min` before entering nested loops to skip inner-loop bounds checking.
