## 2025-02-18 - Avoid array iteration overhead and cache misses in requestAnimationFrame loop
**Learning:** In a high-frequency rendering loop (`requestAnimationFrame` for AR pixel processing), mapping nested loops column-major (x, then y) causes CPU cache thrashing due to the row-major nature of 1D pixel arrays. Also, defining arrays like `[{x, y}]` and iterating them with `.forEach()` inside `requestAnimationFrame` creates unnecessary object allocations causing Garbage Collection micro-stutters.
**Action:** When processing 1D canvas image data arrays representing 2D space, iterate `y` (rows) first, then `x` (columns), and hoist row-invariant calculations out of the inner loop. Avoid creating static arrays and using array methods inside high-frequency loops; use direct variable assignments and manual calculation unrolling instead. Precalculate boundaries (`Math.max`, `Math.min`) outside nested loops.
