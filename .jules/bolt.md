## 2025-10-27 - Optimize AR detection rendering loops
**Learning:** For high-frequency `requestAnimationFrame` loops (e.g., AR tracking or canvas rendering), it is important to avoid allocating new objects or arrays and using array iteration methods like `.forEach()` to prevent Garbage Collection micro-stutters. Unroll static arrays and use direct variable assignments instead. In addition, when iterating over 2D arrays like image pixel data, nested loops should be structured with `y` (rows) as the outer loop and `x` (columns) as the inner loop to ensure contiguous, row-major memory access for cache locality. Loop bounds should be clamped (e.g., using `Math.max` and `Math.min`) before entering the loops instead of executing conditional bounds checks on every iteration.
**Action:** When working with rendering loops, always unroll static data, structure 2D array iterations using row-major order (y outer, x inner), and pre-clamp loop bounds before execution to optimize cache and eliminate inner-loop overhead.
