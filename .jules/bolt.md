## 2024-05-18 - Optimize high-frequency requestAnimationFrame motion detection
**Learning:** In high-frequency 2D array processing loops (like `requestAnimationFrame` reading pixel data), iterating row-by-row (y inner, x outer) thrashes CPU cache because memory is stored row-major. Doing x-inner, y-outer accesses contiguous memory blocks. Additionally, using array methods like `.forEach()` or re-allocating static array blocks inside this loop causes constant garbage collection (GC) micro-stutters.
**Action:** Unroll static iterations to basic assignments. Avoid higher order array functions (`.forEach`) inside hot loops in favor of standard `for` loops. Pre-clamp bounds using `Math.max`/`Math.min` outside nested loops instead of using branching (`continue`) inside the deepest loops. Always arrange inner 2D loops to iterate horizontally (`x`) to maintain spatial cache locality.
